# S3 bucket

## Requirements
- Strong isolation (each user should only be able to access his own data)
- Limited storage (each user can't exceed storage limit)

## Access Policies
1. Dedicated S3 bucket per tenant
2. Shared S3 bucket with prefix-based isolation.
3. Using S3 Access Points.

Source: [Design patterns for multi-tenant access control on Amazon S3](https://aws.amazon.com/blogs/storage/design-patterns-for-multi-tenant-access-control-on-amazon-s3/)
